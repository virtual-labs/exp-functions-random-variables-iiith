Functions of a Random Variable

If XXX is a random variable and Y=g(X)Y = g(X)Y=g(X), then YYY itself is a random variable. Consequently, we can discuss its PMF, CDF, and expected value. The range of YYY can be written as:

RY={g(x)∣x∈RX}where Rx is the range of X \begin{equation} R_Y = \{g(x) | x \in R_X\} \quad \text{where $R_x$ is the range of $X$} \end{equation} RY​={g(x)∣x∈RX​}where Rx​ is the range of X​​

To find the PMF of Y=g(X)Y = g(X)Y=g(X) given the PMF of XXX, we can write:

PY(y)=P(Y=y)=P(g(X)=y)=∑x:g(x)=yPX(x) \begin{equation} P_Y(y) = P(Y = y) = P(g(X) = y) = \sum_{x:g(x) = y} P_X(x) \end{equation} PY​(y)=P(Y=y)=P(g(X)=y)=x:g(x)=y∑​PX​(x)​​

1 Expected Value of a Function of a Random Variable (LOTUS)

Let XXX be a discrete random variable with PMF PX(x)P_X(x)PX​(x), and let Y=g(X)Y = g(X)Y=g(X). Suppose we want to find E[Y]E[Y]E[Y]. One approach is to first find the PMF of YYY and then use the expectation formula E[Y]=E[g(X)]=∑y∈RYyPY(y)E[Y] = E[g(X)] = \sum_{y \in R_Y} y P_Y(y)E[Y]=E[g(X)]=∑y∈RY​​yPY​(y). However, a more convenient method is the law of the unconscious statistician (LOTUS).

Law of the Unconscious Statistician (LOTUS) for Discrete Random Variables:

E[g(X)]=∑xk∈RXg(xk)PX(xk) \begin{equation} E[g(X)] = \sum_{x_k \in R_X} g(x_k)P_X(x_k) \end{equation} E[g(X)]=xk​∈RX​∑​g(xk​)PX​(xk​)​​

This can be proved by expressing E[Y]=E[g(X)]=∑y∈RYyPY(y)E[Y] = E[g(X)] = \sum_{y \in R_Y} y P_Y(y)E[Y]=E[g(X)]=∑y∈RY​​yPY​(y) in terms of PX(x)P_X(x)PX​(x). Typically, using LOTUS is easier than the direct definition when we need E[g(X)]E[g(X)]E[g(X)].

2 Transformations of Random Variables

For a random variable YYY, whether discrete or continuous, and a function g:R→Rg: \mathbb{R} \to \mathbb{R}g:R→R, W=g(Y)W = g(Y)W=g(Y) is also a random variable. Its distribution (pdf), mean, variance, etc., will differ from YYY's. Transformations of random variables are crucial in statistics.

Theorem:

Suppose YYY is a random variable, ggg is a transformation, and W=g(Y)W = g(Y)W=g(Y). Then:

  1. If YYY is discrete, with pmf pYp_YpY​, we have:

E[W]=∑y∈SYg(y)pY(y) \begin{equation} E[W] = \sum_{y \in S_Y} g(y) p_Y(y) \end{equation} E[W]=y∈SY​∑​g(y)pY​(y)​​

  1. If YYY is continuous, with pdf fYf_YfY​, we have:

E[W]=∫−∞∞g(y)fY(y) dy \begin{equation} E[W] = \int_{-\infty}^{\infty} g(y) f_Y(y) \, dy \end{equation} E[W]=∫−∞∞​g(y)fY​(y)dy​​

The cdf-method

The fundamental formula of this theorem helps compute expectations, but it doesn't provide the distribution of W=g(Y)W = g(Y)W=g(Y). To find the cdf FWF_WFW​ of WWW, given the cdf FYF_YFY​ of YYY, we can write:

FW(w)=P[W≤w]=P[g(Y)≤w] \begin{equation} F_W(w) = P[W \leq w] = P[g(Y) \leq w] \end{equation} FW​(w)=P[W≤w]=P[g(Y)≤w]​​

The probability on the right needs to be expressed in terms of YYY. If ggg is strictly increasing, it admits an inverse function g−1g^{-1}g−1 and we can write:

FW(w)=P[g(Y)≤w]=P[Y≤g−1(w)]=FY(g−1(w)) \begin{equation} F_W(w) = P[g(Y) \leq w] = P[Y \leq g^{-1}(w)] = F_Y(g^{-1}(w)) \end{equation} FW​(w)=P[g(Y)≤w]=P[Y≤g−1(w)]=FY​(g−1(w))​​

For strictly decreasing ggg:

P[g(Y)≤w]=P[Y≥g−1(w)] \begin{equation} P[g(Y) \leq w] = P[Y \geq g^{-1}(w)] \end{equation} P[g(Y)≤w]=P[Y≥g−1(w)]​​

In continuous cases, P[Y≥y]=1−FY(y)P[Y \geq y] = 1 - F_Y(y)P[Y≥y]=1−FY​(y), so:

FW(w)=P[g(Y)≤w]=P[Y≥g−1(w)]=1−FY(g−1(w)) \begin{equation} F_W(w) = P[g(Y) \leq w] = P[Y \geq g^{-1}(w)] = 1 - F_Y(g^{-1}(w)) \end{equation} FW​(w)=P[g(Y)≤w]=P[Y≥g−1(w)]=1−FY​(g−1(w))​​

3 Functions of Two Random Variables

E[g(X,Y)]=∑(xi,yj)∈RXYg(xi,yj)PXY(xi,yj) \begin{equation} E[g(X, Y)] = \sum_{(x_i, y_j) \in R_{XY}} g(x_i, y_j) P_{XY}(x_i, y_j) \end{equation} E[g(X,Y)]=(xi​,yj​)∈RXY​∑​g(xi​,yj​)PXY​(xi​,yj​)​​

4 Different Views of a Function of a Random Variable (FRV)

There are several different but essentially equivalent views of a function of a random variable (FRV). We will present two of them, highlighting their differences in emphasis.

Assume we have an underlying probability space P=(Ω,F,P)P = (\Omega, F, P)P=(Ω,F,P) and a random variable XXX defined on it. Recall that XXX is a rule that assigns a number X(ζ)X(\zeta)X(ζ) to every ζ∈Ω\zeta \in \Omegaζ∈Ω. XXX transforms the σ\sigmaσ-field of events FFF into the Borel σ\sigmaσ-field BBB of sets of numbers on the real line. If RXR_XRX​ denotes the subset of the real line reached by XXX as ζ\zetaζ ranges over Ω\OmegaΩ, we can regard XXX as an ordinary function with domain Ω\OmegaΩ and range RXR_XRX​. Now, consider a measurable real function g(x)g(x)g(x) of the real variable xxx.

i) First View (Y: Ω → RY)

For every ζ∈Ω\zeta \in \Omegaζ∈Ω, we generate a number g(X(ζ))=Y(ζ)g(X(\zeta)) = Y(\zeta)g(X(ζ))=Y(ζ). The rule YYY, which generates the numbers {Y(ζ)}\{Y(\zeta)\}{Y(ζ)} for random outcomes {ζ∈Ω}\{\zeta \in \Omega\}{ζ∈Ω}, is an RV with domain Ω\OmegaΩ and range RY⊂RR_Y \subset \mathbb{R}RY​⊂R. For every Borel set of real numbers BYB_YBY​, the set {ζ:Y(ζ)∈BY}\{\zeta : Y(\zeta) \in B_Y\}{ζ:Y(ζ)∈BY​} is an event. Specifically, the event {ζ:Y(ζ)≤y}\{\zeta : Y(\zeta) \leq y\}{ζ:Y(ζ)≤y} is equal to the event {ζ:g(X(ζ))≤y}\{\zeta : g(X(\zeta)) \leq y\}{ζ:g(X(ζ))≤y}.

In this view, the emphasis is on YYY as a mapping from Ω\OmegaΩ to RYR_YRY​, with the intermediate role of XXX being suppressed.

ii) Second View (Input/Output Systems View)

For every value of X(ζ)X(\zeta)X(ζ) in the range RXR_XRX​, we generate a new number Y=g(X)Y = g(X)Y=g(X) whose range is RYR_YRY​. The rule YYY, whose domain is RXR_XRX​ and range is RYR_YRY​, is a function of the random variable XXX. Here, the focus is on viewing YYY as a mapping from one set of real numbers to another. A model for this view is to regard XXX as the input to a system with transformation function g(⋅)g(\cdot)g(⋅). For such a system, an input xxx gets transformed to an output y=g(x)y = g(x)y=g(x), and an input function XXX gets transformed to an output function Y=g(X)Y = g(X)Y=g(X).

In general, we will write {Y≤y}={X∈Cy}\{Y \leq y\} = \{X \in C_y\}{Y≤y}={X∈Cy​} in the sequel. For CyC_yCy​ so determined, it follows that:

P[Y≤y]=P[X∈Cy] \begin{equation} P[Y \leq y] = P[X \in C_y] \end{equation} P[Y≤y]=P[X∈Cy​]​​

If CyC_yCy​ is empty, then the probability of {Y≤y}\{Y \leq y\}{Y≤y} is zero.

Input–Output Model

When dealing with the input–output model, it is convenient to omit references to an abstract underlying experiment and deal directly with the RVs XXX and YYY. In this approach, the observations on XXX are the underlying experiments, events are Borel subsets of the real line R\mathbb{R}R, and the set function P[⋅]P[\cdot]P[⋅] is replaced by the distribution function FX(⋅)F_X(\cdot)FX​(⋅). Then YYY is a mapping (an RV) whose domain is the range RXR_XRX​ of XXX, and whose range RYR_YRY​ is a subset of R\mathbb{R}R. The functional properties of XXX are ignored in favor of viewing XXX as a mechanism that gives rise to numerically valued random phenomena. In this view, the domain of XXX is irrelevant.

Additional discussion on the various views of an FRV is available in the literature.
